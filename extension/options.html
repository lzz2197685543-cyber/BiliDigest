BiliDigest 设置

纯浏览器扩展，不需要任何本地服务或 Python 环境。
字幕来自 B 站接口，总结与聊天使用 DeepSeek。

B 站登录状态

检测中…
未登录时 B 站字幕接口会返回空数组。登录一次即可长期有效。

DeepSeek 登录（用于 AI 总结与聊天）

检测中…
点「登录 / 同步登录态」会打开 chat.deepseek.com。 在那里完成登录后回到本页点「我已完成登录」，token 就会被读取并保存。
如果页面里有登录态但仍读不到，也可以手动粘贴 token（ chat.deepseek.com → F12 → Application → Local Storage → userToken → 取 value）。

字幕测试

填写链接后点「获取字幕」，可直接验证字幕链路是否正常。
这里会执行与页面里完全相同的逻辑（含 cid 校验与重试）， 所以能直接看出是「没登录」「没字幕」还是「其他问题」。

字幕缓存

统计中…
字幕获取成功后本地缓存 6 小时，避免反复请求。 B站接口偶发返回其他视频的字幕，缓存可保证同一视频结果稳定。
